Cycle count setup

Run this once. It creates the four SharePoint lists on the Inventory site and loads the SKU list from the current count sheet. Every step can be run again safely: anything already in place is checked and left alone.

  1. Sign in

    Use your own account. Setup needs the temporary Sites.Manage.All permission on the app registration.

  2. Find the Inventory site

    Looks up airfiltersunlimited.sharepoint.com/sites/Inventory.

  3. Create the lists

    Creates Count SKUs, Count Sessions, Count Entries and SellerCloud Snapshot, then reads every column back to confirm its name and type. Lists that already exist are checked, and any missing columns are added.

  4. Load the SKU list

    Choose the count sheet CSV exported from the current SharePoint list. Only Title, Location and Case Quantity are used. Nothing is written until you confirm the preview.

  5. Check the result

    Reads Count SKUs back from SharePoint and compares every SKU, area and case quantity with the CSV.

When setup passes

  1. In Entra ID, open AFU Cycle Count, then API permissions. On the Sites.Manage.All row, use the ⋯ menu to revoke admin consent, then remove the permission.
  2. On the Inventory site, lock down SellerCloud Snapshot: stop inheriting permissions, remove Inventory Members and Inventory Visitors, grant Inventory Reviewers Contribute.
  3. Do the same for Count SKUs and Count Sessions, except give Inventory Members Read instead of removing them.
  4. Leave Count Entries as it is. Counters need to write to it.
  5. Delete setup.html from the repository.
